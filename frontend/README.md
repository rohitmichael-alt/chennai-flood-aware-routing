# Stage 1 Frontend

This folder contains a static visual frontend for presenting the Stage 1 proof of concept.

Open locally:

```powershell
.\.venv\Scripts\python -m http.server 8080
```

Then visit:

```text
http://localhost:8080/frontend/
```

The page uses:

- `frontend/index.html`
- `frontend/assets/stage1_before_after_route.png`

It explains the Stage 1 workflow, outputs, factors considered so far, limitations, and next stages. It is intended as a clean visual aid for explaining the project to a teacher.
